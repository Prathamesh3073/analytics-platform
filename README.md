# 📊 Business Intelligence Analytics Platform

## 🚀 Overview
An end-to-end analytics platform that processes data, stores it in a database, serves it via a backend API, and visualizes insights through an interactive multi-page dashboard.

---

## 🧠 Features
- Multi-page dashboard (Streamlit)
- Interactive filters (product, region, date)
- KPI metrics (sales, profit, average)
- Smart insights (best product, worst region)
- CSV upload support
- Download filtered data
- Backend API using Flask
- MySQL database integration
- Fallback mechanism for deployment

---

## 🛠️ Tech Stack
- Python
- Pandas
- Streamlit
- Plotly
- Flask
- MySQL
